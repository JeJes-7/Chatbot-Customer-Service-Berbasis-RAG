# Kebijakan Pengembalian Barang TokoTeknoku

## Batas waktu return
Pengembalian barang dapat diajukan maksimal 7 hari kalender setelah barang diterima.

## Syarat return
Barang belum dipakai, segel dan kemasan asli utuh, serta kelengkapan dan aksesori lengkap. Untuk barang cacat atau salah kirim, wajib menyertakan video unboxing tanpa terputus.

## Proses refund
Setelah barang diterima dan lolos pengecekan, refund diproses dalam 3-5 hari kerja ke metode pembayaran awal. Biaya kirim return ditanggung TokoTeknoku jika barang cacat atau salah kirim, dan ditanggung pelanggan jika alasan return adalah berubah pikiran.

## Barang yang tidak dapat dikembalikan
Software berlisensi yang sudah diaktivasi, voucher digital, dan produk promo bertanda "Final Sale".
